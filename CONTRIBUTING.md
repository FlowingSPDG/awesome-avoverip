# Contributing

Contributions to Awesome AV over IP are welcome.

## Inclusion Criteria

Items must:

1. Be **directly related** to AV over IP standards, protocols, tools, or products
2. Have a **working official URL**
3. Include a **concise description** of what it does
4. Be **currently available** (or have a clear public roadmap)

## Do Not Add

- Generic blog posts or news articles (except in Learning Resources)
- Unmaintained forks without clear value
- Affiliate links

## Pull Request Process

1. Fork and create a branch
2. Edit `README.md` and/or `docs/research.md`
3. Open a PR with a clear description
4. Link to official documentation where possible

## Style Guide

- Use official standard names (e.g., SMPTE ST 2110, NDI, OMT)
- Follow vendor official spelling
- English preferred for list entries; technical terms in English
